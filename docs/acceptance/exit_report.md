# Informe de salida

## Resumen Ejecutivo

El presente proyecto tuvo como objetivo desarrollar un modelo de Machine Learning capaz de predecir la probabilidad de éxito de oportunidades comerciales B2B a partir de la información histórica del pipeline de ventas. La intención fue generar una herramienta que apoyara la toma de decisiones comerciales y permitiera priorizar aquellas oportunidades con mayores posibilidades de convertirse en ventas exitosas.

Para lograrlo, se siguieron diferentes etapas, desde el entendimiento del negocio y la preparación de los datos hasta el entrenamiento y evaluación de varios modelos predictivos. Después de comparar los resultados obtenidos, el modelo Random Forest fue seleccionado como la mejor alternativa debido a su buen desempeño y a su capacidad para identificar correctamente oportunidades con potencial de éxito.

Los resultados del proyecto demuestran que el uso de técnicas de Machine Learning puede aportar valor a los procesos comerciales, ayudando a optimizar recursos y facilitando decisiones basadas en datos.

## Resultados del proyecto

A lo largo del proyecto se alcanzaron diferentes entregables y logros en cada una de sus etapas. Inicialmente, se realizó el entendimiento del problema de negocio y se identificaron las variables disponibles dentro del pipeline comercial. Posteriormente, se llevó a cabo la limpieza y preparación de los datos, incluyendo el tratamiento de valores faltantes y la transformación de variables para hacerlas aptas para el modelamiento.

Una vez preparado el conjunto de datos, se entrenaron y evaluaron distintos modelos de clasificación con el fin de identificar cuál ofrecía mejores resultados. Entre los modelos evaluados, Random Forest fue el que presentó el desempeño más equilibrado y consistente.

La comparación con el modelo base evidenció que Random Forest logró mejores resultados en las métricas consideradas más relevantes para este caso de estudio, especialmente Recall y F1-Score. Esto fue importante porque permitió identificar una mayor cantidad de oportunidades con posibilidad real de convertirse en ventas exitosas.

Estos resultados son relevantes para el negocio, ya que proporcionan una herramienta de apoyo para priorizar esfuerzos comerciales, enfocar recursos en oportunidades con mayor potencial y fortalecer la toma de decisiones basada en evidencia.

## Lecciones aprendidas

Uno de los principales desafíos encontrados durante el desarrollo del proyecto estuvo relacionado con la calidad de los datos. Fue necesario dedicar tiempo a revisar inconsistencias, manejar valores faltantes y comprender el significado de cada variable para garantizar que la información utilizada fuera confiable.

Otra lección importante fue entender que el conocimiento del negocio es tan importante como la parte técnica. Comprender cómo funciona el proceso comercial permitió interpretar mejor los resultados y seleccionar métricas alineadas con las necesidades reales de la organización.

En cuanto al modelamiento, se evidenció que el modelo más complejo no siempre es el mejor. La evaluación cuidadosa de diferentes alternativas permitió seleccionar una solución equilibrada y adecuada para el problema planteado.

Para futuros proyectos de Machine Learning, se recomienda fortalecer los procesos de captura y almacenamiento de datos, documentar adecuadamente las variables utilizadas y mantener una comunicación constante entre los equipos técnicos y las áreas de negocio.

## Impacto del proyecto

Este proyecto demuestra que el análisis predictivo puede convertirse en una herramienta útil para apoyar la gestión comercial en entornos B2B.

La implementación de un modelo como el desarrollado puede ayudar a que los equipos comerciales prioricen oportunidades con mayor probabilidad de éxito, optimicen el uso de sus recursos y dediquen más esfuerzo a aquellas propuestas que generen un mayor valor para la organización.

Adicionalmente, este trabajo abre la posibilidad de futuras mejoras, como integrar el modelo dentro de plataformas CRM, actualizar periódicamente sus predicciones con nueva información e incorporar variables adicionales que permitan aumentar su precisión y utilidad práctica.

## Conclusiones

Los resultados obtenidos permitieron comprobar que es posible utilizar datos históricos del pipeline comercial para predecir el resultado de oportunidades de negocio mediante técnicas de Machine Learning.

El modelo Random Forest fue seleccionado como la mejor alternativa debido a su desempeño general y a su capacidad para identificar adecuadamente oportunidades con potencial de éxito. Esto demuestra que las herramientas analíticas pueden complementar la experiencia de los equipos comerciales y aportar información valiosa para la toma de decisiones.

Finalmente, se concluye que el uso de modelos predictivos en ventas representa una oportunidad para mejorar la eficiencia de los procesos comerciales y fomentar una cultura organizacional basada en el uso estratégico de los datos. Asimismo, se recomienda continuar explorando nuevas fuentes de información y realizar actualizaciones periódicas del modelo para mantener su efectividad en el tiempo.
